# 📱 **Scientific Calculator - Android App**  

## **Overview**  
The **Scientific Calculator** is an Android-based application that provides **basic and advanced mathematical functions** in an intuitive and user-friendly interface. Designed for **students, engineers, and professionals**, this app offers a powerful calculation tool right at your fingertips.

## **Features**  
- ➕ **Basic Arithmetic Operations**: Addition, subtraction, multiplication, and division.  
- 🔢 **Advanced Functions**: Square root, power, logarithm, and exponential functions.  
- 📏 **Trigonometric Calculations**: Compute sine, cosine, tangent, and inverse functions.  
- 🔄 **Factorial & Modulo Operations**: Perform mathematical operations with ease.  
- 📱 **User-Friendly Interface**: Responsive and easy-to-use UI with a dark mode option.  
- 💾 **Calculation History**: Save and review previous calculations.  
- 🚀 **Optimized for Performance**: Lightweight, fast, and responsive for all Android devices.  

## **Technologies Used**  
- **Java/Kotlin** for backend logic  
- **Android Studio** for development  
- **XML & Material Design** for UI/UX  
- **Jetpack Components** for modern app architecture

## **Installation & Usage**  

### **1. Clone the Repository**  
```bash
git clone https://github.com/nikunjangc/ScientificCalculator.git
cd ScientificCalculator
2. Open the Project in Android Studio
Open Android Studio and select "Open an existing project".
Navigate to the project folder and click OK.
Allow Gradle to sync dependencies.
3. Build & Run the App
Connect an Android device or use an emulator.
Click Run ▶ in Android Studio.
4. Download & Install (APK)
Alternatively, download the APK from the Releases section and install it on your Android device.

How to Use
Launch the App on your Android device.
Enter a mathematical expression using the on-screen keypad.
Press "=" to compute the result instantly.
Use scientific functions such as log, sin, cos, tan, and exponentiation for advanced calculations.
Check Calculation History to review previous results.
